## 一、这是什么项目

联网多人在线**架空王朝**官场生存模拟器。玩家从从九品书办爬到正一品首辅。

### 硬边界（不可协商）
- 世界观**完全虚构**：王朝「大衍」、官署、官阶、人物全部架空，**不映射任何现实机构**。
  用户曾要求改回现实官职体系，已拒绝并坚持架空版本 —— 不要再提。
- 单机版与联机版共用同一套数值口径，改动需保持两边一致（或明确标注「单机先行」）。

### 在线地址
- **单机版（主要交付物）**：https://houhuizhang80-wq.github.io/daiyan-empire/
  （GitHub Pages，直接服务仓库根目录的 `daiyan-offline.html`，双击本地文件也能玩）
- 联机版：未部署（server/ 代码在仓库里，部署产物 Docker/systemd/nginx 齐全，服务默认 8787 端口）

## 二、仓库与部署纪律

- remote = `git@github.com:houhuizhang80-wq/daiyan-empire.git`，**必须走 SSH**
  （本机 `github.com:443` 不通；`~/.ssh/id_ed25519` 已登记在 GitHub 账号 houhuizhang80-wq 下）
- **推送流程**：单独执行 `git push origin main`；不要把 commit 和 push 合并在一条命令里跑
  （沙箱环境下合并跑更容易触发对 `~/.ssh` 的授权拦截）。push 时用户需在授权弹窗点允许。
- `.gitignore` 已加固：`data/`（存档+密钥）、`.workbuddy/`、`2026-*.md`、`publish_*/`、`*.genie`
- **Pages 更新有 ~1 分钟延迟**；推送后验证方式：抓取线上 HTML 检查新功能关键词

- **出身**：5 种 + 承先人之荫（传承二代目）；**随机朝局** 4 变体（主少国疑/党势失衡/缺额紧张/承平）

- **周期系统**：朝议每 12 回合（按党势比掷胜负）、京察每 24 回合（劣档镌级）、大案 6 条（河工/驿传/科场/仓廪/盐引/冤狱，rank 门槛 5/5/6/7/8/4，一案一审不复用）、圣心（务实/清议每 10~18 回合翻转）
- **权力**：参劾罢黜（下官降级）、擢升亲信（门生真升官+孝敬闭环）、裁决大案、党库提用

- **传承**：家谱（generation/lineage/familyRep 家声/家风 careful|aristocrat/enemies/patrons/proteges）；罢黜断绝

## 五、开发纪律（改单机版的标准流程）

1. 改 `daiyan-offline.html` → 跑 `node scripts/offline-smoke.js` **必须 0 fail 且 exit 0**
2. UI 改动 → 无头截图验证（puppeteer-core + Chrome for Testing，多视口查横向溢出；
   Chrome 路径与脚本模板见 `~/.workbuddy/MEMORY.md`「前端 UI 无头截图验证」节）
3. commit → 单独 push → 抓线上 HTML 验证关键词
4. 测试新增机制时**用确定性数据**，不要依赖早前测试节点留下的状态（历史上第 18 节建的
   nemesis 到 26 节消失过一次，原因未定位，已加「30 回合死仇仍在」持久性断言兜底）

### 踩过的坑（别再踩）
- **`apRel` 只在 d>0 时新建关系**，负增量（仇怨）会被静默丢弃 —— 造敌对关系要直接 push
- **配色类撞车**：给元素加语义色类前先确认没被别的组件当形状类用（`.seal` 撞车把 pill 撑成
  30px 白字方块；断语配色类已改 `tone-` 前缀，顶栏印章改 `.brand-seal`，有防回归断言）
- **银两收支必须走 `silverScale`（=俸禄/40）**：新增行动/事件含银两时，成本走 `silverNeedOf`、
  事件走 resolveEvent 的缩放分支，否则回到「末吏用不起、首辅白嫖」的坏口径
- **田产类风声数值要对齐自然衰减量**（衰减 -7/回合，风声 0.15/处会被完全掩盖，调到 0.5 并有断言）
- jsdom 无布局（getBoundingClientRect 全 0），DOM 断言只能查类名/textContent，不能查尺寸
- 跨节点测试的世代/次数断言用相对值（如 `generation === 上一份+1`），写死绝对值必崩
